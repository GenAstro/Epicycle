EpicycleIO.band — Function
band([panel], x, lower, upper; attributes...)

Draw a filled region between two bounds — a covariance envelope around residuals.

Draw the band before the data that sits inside it, so the points land on top rather than under.

Arguments

  • panel: optional leading string naming the panel.
  • x: the horizontal axis, shared by both bounds.
  • lower, upper: the two edges, each the same length as x.

Notes

This is the one wrapper with no Plotly trace behind it. Plotly has no band, so this builds a closed polygon — x forward along the upper bound and back along the lower — and fills it.

Returns

nothing. The panel is drawn on the dashboard.

Examples

band("Residuals", t, -3 .* σ, 3 .* σ; name = "3σ", fillcolor = "rgba(120,120,120,0.25)")
xyplot!("Residuals", t, residual; mode = "markers", name = "residual")

EpicycleIO.clear! — Function
clear!(panel = "Plot")

Empty a panel but leave it on the dashboard.

Arguments

  • panel: the panel to empty. Without one you get the default panel.

Notes

The layout survives: a panel set to a log axis is still a log axis after clearing, so refilling it does not mean configuring it again.

Clearing a panel that does not exist does nothing, silently. Emptying a script's panels before filling them, so a re-run starts fresh rather than accumulating, is an ordinary thing to write — and the first time it runs, those panels are not there yet.

Returns

nothing. The emptied panel is republished, so the browser follows.

Examples

clear!("Altitude")

EpicycleIO.clear_all! — Method
clear_all!()

Remove every panel from the dashboard.

clear! empties one panel and leaves it in place; this takes them all away, layout and all, and the next plot starts from an empty page.

Notes

The browser follows. Forgetting the panels here without saying so would leave the page showing panels that no longer exist, and the next plot would appear among the ghosts.

Panel files left in the served directory are deleted too, all of them rather than only this session's. The directory outlives the process, so otherwise it fills with orphans from every earlier run.

Returns

nothing.

Examples

clear_all!()          # a script that starts from a clean dashboard

EpicycleIO.open_dashboard — Method
open_dashboard()
open_dashboard(panel, more...)

Open the dashboard in a browser tab.

With no arguments you get every panel. Naming panels opens a tab showing only those, which is how you spread twelve plots across a few windows without splitting where they live:

open_dashboard("Range residuals", "Range-rate residuals")   # navigation, in its own tab
open_dashboard("Porkchop")                                  # one plot, full size

The panels are still one set on one server. A scoped tab is a view of it, so a panel that several tabs show updates in all of them.

Arguments

  • titles: the panels to show. With none, the tab shows every panel.

Notes

Opens a tab through the operating system's usual handler. If that fails — no browser, or a headless machine — you get a warning carrying the URL rather than an error, because failing to open a window is not a reason to stop a run.

Returns

nothing.

EpicycleIO.orbitview — Method
orbitview([panel], sat; kwargs...)

Draw a spacecraft's propagated trajectory in three dimensions, with a clock you can play.

The panel joins the dashboard beside any plots, so a trajectory and the quantities describing it share one page.

Everything is read from the spacecraft:

  • the trajectory, from sat.history
  • the epoch, from the earliest recorded sample
  • one coloured arc per propagation segment, from the same palette the plots use
  • the name shown on the entity, from sat.name
propagate!(prop, sat, StopAt(sat, PropDurationDays(), 1.0))

orbitview(sat)
orbitview("Mission", sat)          # name the panel

Arguments

  • panel: optional leading string naming the panel.
  • sat: the spacecraft. It must have been propagated — the trajectory is read from its history.

Keyword arguments

  • colors: palette for the arcs, cycled. Defaults to the shared palette, so a trajectory and the plots of it match.
  • linewidth: arc width in pixels.
  • speed: initial playback rate, in simulated seconds per real second. :auto fits the whole trajectory into about two minutes.

Notes

Positions go to the browser in the inertial frame and Cesium applies the rotation to fixed itself, so the orbit holds still against the stars and the body turns beneath it. The epoch is converted to UTC on the way out, whatever scale the history was recorded in, because Cesium reads times as UTC.

An impulsive burn is marked with a point labelled with its ΔV, differenced from the velocities either side of it rather than taken from whatever commanded it.

Earth is the only central body today.

Returns

nothing. The view is drawn on the dashboard.

Throws an ArgumentError if the spacecraft has no propagated history, or if nothing in that history is long enough to draw an arc.

EpicycleIO.panel! — Function
panel!([panel]; layout...)
panel!([panel], layout::PlotlyBase.Layout)

Set a panel's titles, axis labels, scales and limits.

Arguments

  • panel: the panel to configure. Without one you get the default panel.
  • layout...: Plotly layout attributes. Nested settings are spelled with underscores, so yaxis_type reaches Plotly as yaxis.type.

Notes

Settings accumulate rather than replace, so calling this twice for the same axis keeps both. Limits are an ordered pair, so an axis runs backwards if you give them backwards. A Dict is not a way in — write legend_orientation = "h", not legend = Dict("orientation" => "h").

Configuring a panel that does not exist yet is allowed and creates it empty, which is what lets you set a panel up before plotting into it. A name that was meant to reach an existing panel and does not earns a warning naming the panels there are.

Returns

nothing. The panel is republished with the new layout.

Examples

panel!("Altitude"; xaxis_title = "hours from epoch", yaxis_title = "km", yaxis_type = "log")

panel!("Decay"; xaxis_range = [6, 0])            # runs backwards

EpicycleIO.position_difference — Method
position_difference(a, b) -> Vector{Float64}

The distance between two trajectories at each epoch of a that b covers, in km.

Arguments

  • a: The reference, a SpacecraftHistory or a Spacecraft.
  • b: The trajectory compared with it, a SpacecraftHistory or a Spacecraft.

Notes

  • b is interpolated at a's epochs and expressed in a's coordinate system before the difference is taken. Epochs of a that b does not cover are skipped.
  • At an epoch two segments of b share, the later segment applies, as in state_at.

Returns

A vector of distances in km, one per epoch of a covered by b.

Examples

using Epicycle
t0 = Time("2026-10-21T00:00:00", UTC(), ISOT())
sat = Spacecraft(state = CartesianState([7000.0, 0, 0, 0, 7.5, 1.0]), time = t0)
prop = OrbitPropagator(ForceModel(PointMassGravity(earth, ())), IntegratorConfig(DP8(); abstol = 1e-12, reltol = 1e-12))
propagate!(prop, sat, StopAt(sat, PropDurationSeconds(), 1800.0))
path = tempname() * ".oem"
write_ephemeris(path, sat; step = 60.0)
maximum(position_difference(read_ephemeris(path), sat)) < 1e-6

# output

true

EpicycleIO.read_ephemeris — Method
read_ephemeris(path; format, kwargs...) -> SpacecraftHistory

Read an ephemeris file into a SpacecraftHistory: CCSDS OEM, STK .e or JPL SPK.

Arguments

  • path: The file. Its extension, .oem, .e or .bsp, chooses the format.
  • format: OEM(), STKEphemeris() or SPK(), when the extension does not say.
  • strict: Treat every correction as an error. Default false.
  • skip_bad_lines: OEM and STK. Drop an unreadable data line, with a warning, and split the segment there. Default false.
  • ref_frame, center: Names to read in place of the file's frame and centre, such as "EME2000" and "EARTH". time_system: OEM only. Each override is recorded in the diagnostics with the file's original value.
  • naif_id: SPK. The object to read, when the file holds more than one.
  • step: SPK. Seconds between samples for SPK types that store none, such as Chebyshev.

Notes

  • Each segment of the file is a segment of the history, in the coordinate system the file names. Interpolation never crosses from one segment to the next.
  • A file's problems are reported all at once. What can be corrected without changing the data is corrected and listed in one warning; the rest stops the read with an EphemerisReadError giving every problem with its line. diagnostics returns what was corrected or assumed.
  • Beyond times and states, each segment's metadata holds the declared interpolation, accelerations and covariance where the file has them (km, km/s, km/s², km² and so on), the object's name and ID, the usable span, and the file's details.

Returns

A SpacecraftHistory, one segment per file segment.

Examples

using Epicycle
t0 = Time("2026-10-21T00:00:00", UTC(), ISOT())
sat = Spacecraft(state = CartesianState([7000.0, 0, 0, 0, 7.5, 1.0]), time = t0, name = "SAT")
prop = OrbitPropagator(ForceModel(PointMassGravity(earth, ())), IntegratorConfig(DP8(); abstol = 1e-12, reltol = 1e-12))
propagate!(prop, sat, StopAt(sat, PropDurationSeconds(), 1800.0))
path = tempname() * ".oem"
write_ephemeris(path, sat; step = 60.0)
eph = read_ephemeris(path)
length(epochs(eph))

# output

EpicycleIO.report — Method
report(path; columns...)

Write named columns to a delimited text file.

The keywords become the column headings, so they are your words rather than whatever the quantity happens to be called — someone who did not write the run has to read this. A vector-valued column expands into components, so position becomes position_1, position_2, position_3.

report("flight.txt"; time = [x.jd for x in t], position = r, velocity = v)

Arguments

  • path: the file to write. An existing file is overwritten.
  • delim: what separates the columns. Two spaces by default.
  • columns...: the data, one keyword per column. Every column must be the same length.

Notes

Columns carry no units of their own — they are written as given, so name the keyword for what the number is (altitude_km) if the reader will need to know.

Values must render on one line. An epoch does not, so convert it first — t.jd, t.mjd or t.isot — and the file then records which scale and format you meant.

Returns

The path written, so it can be passed straight on to something that reads it.

Throws an ArgumentError if no columns are given, if the columns differ in length, or if a value's printed form spans lines and would break a row.

EpicycleIO.state_at — Method
state_at(eph, t; overlap = :error) -> Coordinate

The interpolated state at t, with its coordinate system and epoch.

Arguments

  • eph: A SpacecraftHistory, or a Spacecraft.
  • t: The epoch, in any time scale.
  • overlap: Where two segments' usable spans overlap: :error (default), :earlier or :later.

Notes

  • The segment that covers t is interpolated with its declared method, Lagrange degree 7 when none is declared, and never with points from another segment.
  • At an epoch two segments share, such as a maneuver, the later segment applies: the state after the event.
  • t outside every segment, inside a gap, is an ArgumentError naming the nearest covered times. A time within 1 µs of a segment's first or last epoch is taken as that epoch, since files store epochs to finite precision.
  • Hermite interpolation uses the tabulated velocities. Lagrange interpolates positions and velocities independently, as OEM and STK readers do; where a file has positions only, the velocity is the derivative of the position polynomial.

Returns

A Coordinate in the segment's coordinate system.

Examples

using Epicycle
t0 = Time("2026-10-21T00:00:00", UTC(), ISOT())
sat = Spacecraft(state = CartesianState([7000.0, 0, 0, 0, 7.5, 1.0]), time = t0)
prop = OrbitPropagator(ForceModel(PointMassGravity(earth, ())), IntegratorConfig(DP8(); abstol = 1e-12, reltol = 1e-12))
propagate!(prop, sat, StopAt(sat, PropDurationSeconds(), 600.0))
c = state_at(sat, Time("2026-10-21T00:05:00", UTC(), ISOT()))
round(to_vector(CartesianState(c))[1]; digits = 3)

# output

6637.168

EpicycleIO.write_ephemeris — Method
write_ephemeris(path, source; format, coordinate_system, step, interpolation, time_system,
                naif_id, object_name, object_id, originator, version, digits,
                discard_unsupported) -> String

Write a spacecraft's trajectory, or any SpacecraftHistory, to an ephemeris file: CCSDS OEM, STK .e or JPL SPK.

Arguments

  • path: The file to write. Its extension, .oem, .e or .bsp, chooses the format; it is replaced if it exists.
  • source: A Spacecraft, whose history is written, or a SpacecraftHistory, such as one from read_ephemeris.
  • format: OEM(), STKEphemeris() or SPK(), when the extension does not say.
  • coordinate_system: Write in this coordinate system, converting every state. Default: each segment's own, except for SPK, which is written in ICRF axes about the segment's origin.
  • step: Resample every segment every step seconds, each segment's first and last epochs included, by interpolating it. Default nothing: the epochs as they are.
  • interpolation: The method the file declares, such as Hermite(7). Default: what the source declares, else Lagrange(7).
  • time_system: OEM. The time system epochs are written in, e.g. UTC() (default) or TDB(), or "GPS".
  • naif_id: SPK. The object's NAIF ID; required for SPK.
  • object_name, object_id: The object. Default: the source's, else the spacecraft's name, else "UNKNOWN".
  • originator: OEM. Who made the file. Default "EPICYCLE".
  • version: OEM. "3.0" (default) or "2.0".
  • digits: OEM and STK. Decimal places of seconds in written epochs. Default 9.
  • discard_unsupported: SPK. Write without accelerations and covariance, which SPK cannot hold, rather than refuse. Default false.

Notes

  • Every rule of the format is checked before the file is opened, and every problem is reported in one ArgumentError. Nothing is written on failure, and an existing file is left as it was.
  • Each segment of the history is a segment of the file, so a maneuver stays a discontinuity. The one-state segment maneuver! records repeats the first state of the propagation after it and is not written.
  • What the source carries beyond states (accelerations, covariance) is written where the format can hold it. A conversion to another coordinate system rotates states only: a source with accelerations or covariance in another frame is refused rather than written half-converted.

Returns

path.

Examples

using Epicycle
t0 = Time("2026-10-21T00:00:00", UTC(), ISOT())
sat = Spacecraft(state = CartesianState([7000.0, 0, 0, 0, 7.5, 1.0]), time = t0)
prop = OrbitPropagator(ForceModel(PointMassGravity(earth, ())), IntegratorConfig(DP8(); abstol = 1e-12, reltol = 1e-12))
propagate!(prop, sat, StopAt(sat, PropDurationSeconds(), 600.0))
path = tempname() * ".e"
write_ephemeris(path, sat; step = 60.0, interpolation = Hermite(7))
filter(startswith("InterpolationSamplesM1"), readlines(path))

# output

1-element Vector{String}:
 "InterpolationSamplesM1  3"

EpicycleIO.xyplot — Method
xyplot([panel], x, y; attributes...)
xyplot([panel], y; attributes...)

Draw a line, replacing whatever was in the panel.

The leading string names a panel; without one you get the default panel. Plotting into a name that already exists replaces it, so re-running a script gives you one figure rather than twenty. Use xyplot! to add instead.

Attributes are Plotly's, passed through untouched:

xyplot(t, altitude; name = "altitude", mode = "lines", line_color = "cyan", line_width = 2)

A matrix or a vector of vectors draws one line per component, which is what a position column from history already is:

xyplot(t, r; name = ["x", "y", "z"], line_color = ["red", "green", "blue"])

Arguments

  • panel: optional leading string naming the panel.
  • x, y: paired arrays. Several pairs may follow one another, each with its own length. Given y alone, the horizontal axis is its index.

Notes

x and y are plain arrays and carry no units, frame or time system of their own — whatever you computed them in is what gets drawn, so label the axes with panel!. A Time is not a number: render it first, or subtract the epoch to get hours.

A NaN or an Inf draws as a break in the line rather than raising.

Returns

nothing. The panel is drawn on the dashboard, and a browser tab opens if none is watching.

PlotlyBase.scatterpolar — Function
scatterpolar([panel], θ, r; attributes...)

Draw against angle and radius — a ground station pass, an antenna pattern.

Arguments

  • panel: optional leading string naming the panel. Without one you get the default panel.
  • θ: angle, in degrees unless you pass thetaunit = "radians".
  • r: radius, in whatever units the radial axis is set to.

Notes

thetaunit converts the angle for you. There is no equivalent for the radial axis, so an elevation in radians plotted against a degree range puts every point on the rim — convert it yourself. A polar trace cannot share a panel with a cartesian one; Plotly draws them on different subplot types.

Returns

nothing. The panel is drawn on the dashboard.

Examples

scatterpolar("Sky view", azimuth, rad2deg.(elevation); mode = "lines", name = "Pass 3")

panel!("Sky view";
       polar_angularaxis_direction = "clockwise",   # compass sense
       polar_angularaxis_rotation  = 90,            # north at the top
       polar_radialaxis_range      = [90, 0])       # zenith at the centre

PlotlyBase.surface — Function
surface([panel], x, y, Z; attributes...)
surface([panel], Z; attributes...)

Draw a scalar field over a grid, as a surface in three axes — a porkchop plot, a coverage map.

Arguments

  • panel: optional leading string naming the panel.
  • x: the horizontal axis, one value per column of Z.
  • y: the vertical axis, one value per row of Z.
  • Z: the field, indexed [row, column], so size(Z) == (length(y), length(x)).

Given Z alone, the axes are its indices.

Notes

Rows follow y and columns follow x. That is Plotly's convention, and it is why the horizontal axis is the second index rather than the first — the shape is checked, so a transposed grid is refused rather than drawn sideways.

Returns

nothing. The panel is drawn on the dashboard.

Examples

surface("Porkchop", departure_days, arrival_days, C3;
         colorscale = "Viridis", colorbar_title = "C3 km²/s²")

EphemerisReadError(path, problems)

The error thrown when an ephemeris file has problems the reader cannot correct. It lists every problem found, not only the first.

Fields

  • path: The file read.
  • problems: Every Diagnostic of severity :error, in file order.

  • hint: A suggestion for how to proceed, or an empty string.
