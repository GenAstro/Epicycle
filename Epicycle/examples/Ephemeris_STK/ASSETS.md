# Data files

## gmat_leo.e

A reference ephemeris read by `Ex_EphemerisSTK.jl`: two hours of a low Earth orbit under point-mass
Earth gravity, at 60 s steps, written by GMAT R2026a. GMAT's Earth gravitational parameter was set
to Epicycle's, 398600.4418 km³/s², so an Epicycle propagation from the same state follows the same
orbit.

- Source: generated by `EpicycleIO/test/truth/ephemeris_truth.script`, run with GMAT R2026a, which
  writes the CCSDS OEM, STK `.e` and SPK versions of the same trajectory.
- Size: 20350 bytes, as stored in the repository
- SHA-256: `b3bf5e8cfc9e866f1e2bddb9bdf3e2db7db20755e987847f903b63bec12a5622`, as stored in the repository (LF line endings; GMAT on Windows
  writes CRLF, which git normalizes, and the readers accept either)

defined in this repository.
